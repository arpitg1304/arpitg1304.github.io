# arpitg1304.github.io

Personal site of Arpit Gupta: robot-learning data infrastructure, research and open source.

Hand-built static site with no build step, served by GitHub Pages straight from `main`.

```
index.html              all content
assets/css/style.css    design tokens (dark/light) + components
assets/js/main.js       interactions: hero arm sim, Amdahl calculator, live GitHub stars, filters
assets/img/concepts/    animated concept illustration per project (see STYLE.md there)
assets/img/archive/     grad-school project stills + GIFs
```

Run locally: `python3 -m http.server` and open http://localhost:8000.
