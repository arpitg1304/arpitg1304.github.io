# arpitg1304.github.io

Personal site of Arpit Gupta: robotics engineering, research and open-source tools.

A static site with no build step, served by GitHub Pages from `master`.

```
index.html              landing page: headline, section links, contact
experience.html         roles, education, patents, short bio
stack.html              work by layer: sensors, robot software, learning, platform
research.html           CoRL 2026 paper and an Amdahl's-law calculator
projects.html           open-source projects and graduate-school archive
interests.html          research interests and tools
flywheel.html           system overview (linked from the footer)
assets/css/style.css    design tokens (light/dark) and components
assets/js/main.js       nav, theme, contact dialog, filters, live GitHub stars, calculator
assets/js/flywheel.js   system overview animation
assets/img/concepts/    animated SVG illustration per project (see STYLE.md; simpler alternates in simple/)
assets/img/archive/     graduate-school project stills and clips
```

Run locally: `python3 -m http.server` and open http://localhost:8000.
