Python · PyPI★ 184

Forge

Format conversion, quality scoring and cataloging for robot learning datasets.

Reads nine robot learning formats (LeRobot v2 and v3, RLDS, MCAP, RoboDM, GR00T, HDF5, Zarr and rosbag) and writes LeRobot v3, RLDS, MCAP and RoboDM through a shared Episode/Frame representation, so each new reader works with every writer. Scores episodes on proprioceptive quality metrics (LDLJ smoothness, dead actions, gripper chatter) and registers them in a DuckDB catalog that supports SQL queries, SigLIP semantic search and deduplication.

$ pip install forge-robotics
$ forge quality hf://lerobot/pusht

ROS Time Machine

Event-triggered data recording for ROS 2.

Keeps a rolling in-memory buffer of every topic. When a trigger fires, it writes the pre-event buffer and the live post-event recording to a single MCAP file. Version 2 adds semantic triggers: events described in plain language ("the cup falls from the gripper") are detected by a vision-language model sampling the cameras at 1 Hz. Each clip is anchored to the time of the event, not the time of detection, so model latency does not cost pre-event data. On 45 replayed SO-101 policy rollouts, it detected 44 of 46 labeled events.
