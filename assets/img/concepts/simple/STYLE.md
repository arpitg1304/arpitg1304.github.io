# Concept illustration style (v2)

One simple, animated SVG per project. An alternative, simpler set; the site uses the detailed set in the parent folder.

All eight are generated by `gen.py` so they stay one family:

```
python3 gen.py .    # run inside this folder; writes the eight SVGs
```

- Canvas `800x500`, background `#0a0e14` with a faint dot grid. No external fonts or images.
- One focal idea per image, 3 to 8 labels, generous empty space.
- Palette: ink `#d6dee8`, dim `#6b7a90`, line `#2a3647`, cobalt `#7aa2ff` (focal element),
  cyan `#4cc9f0` (data flow), green `#34d399` (pass / selected), violet `#a78bfa` (models), red `#f43f5e` (failure).
- One calm loop per image (3 to 8 s). Respects `prefers-reduced-motion` for CSS animation.
- After regenerating, bump the `?v=` on the image links in `projects.html`.
