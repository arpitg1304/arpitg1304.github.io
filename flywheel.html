System overview

A closed-loop pipeline for improving deployed robot policies.

The pipeline connects deployment, data capture, curation, training, evaluation and release, with an open-source tool at each stage. ROS Time Machine and a vision-language model capture field failures. Forge and Anvil curate them into training data. Armature evaluates candidate policies in simulation. Anvil and Robotics Agent Skills support release to the fleet. Figures shown are illustrative.
